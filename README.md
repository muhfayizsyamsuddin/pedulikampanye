# PeduliKampanye AI

PeduliKampanye AI adalah chatbot berbasis kecerdasan buatan yang membantu organisasi sosial menyusun draf kampanye donasi, membuat FAQ untuk calon donatur, dan memeriksa kelengkapan informasi kampanye.

Project ini dibuat untuk memenuhi tugas Day 18 — OpenRouter and Chatbots, Maxy Academy.

## Fitur

- Membuat draf kampanye donasi.
- Menyusun FAQ untuk calon donatur.
- Membuat checklist transparansi kampanye.
- Menandai informasi yang belum tersedia agar tidak dianggap sebagai fakta.
- Percakapan dengan AI melalui antarmuka web.
- Tampilan respons menggunakan Markdown.
- Validasi input dan pembatasan request dasar.

## Teknologi

- PHP 8.3+
- Laravel 13
- Blade
- Tailwind CSS
- JavaScript
- OpenRouter API
- Marked
- DOMPurify

## Cara menggunakan

1. Buka aplikasi PeduliKampanye AI.
2. Masukkan instruksi kampanye donasi pada kolom percakapan.
3. Gunakan saran fitur untuk membuat kampanye, menyusun FAQ, atau memeriksa transparansi.
4. Periksa kembali semua hasil AI dan lengkapi informasi yang masih belum tersedia sebelum dipublikasikan.

## Batasan saat ini

Project merupakan prototipe chatbot. Penyimpanan riwayat percakapan secara permanen, autentikasi pengguna, serta pengelolaan kampanye melalui database belum menjadi bagian dari implementasi awal.
